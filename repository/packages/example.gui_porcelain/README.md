# Example: Porcelain Fairway GUI (a GUI theme mod)

A quiet, modern light design - the opposite end of the shelf from Neon
Fairway, built from exactly the same file shape. Where Parchment is
vintage, Porcelain is minimal: near-flat white surfaces (`shadow_size`
4, hairline green-grey borders), one fairway green doing the primary
work, and gold kept only where the stock interface spends it.

Two **rules** finish the design: labels on the main menu set a touch
larger (16pt), and panels on the Settings screen sharpen to a 6px
radius - targeted changes a global palette cannot express. The bottom
bar's turf goes pale to match, through the `bottom_bar` roles.

This is also the friendliest example to **remix**: its palette is close
to a wireframe, so changing `primary` and `accent` alone re-brands the
whole game in two lines. See docs/modding/gui-themes.md.
